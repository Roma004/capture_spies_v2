# Новые приключения неуловимых 18 или "Заговор шпионов"

Новый семестр и новые проблемы. На этот раз наши отважные герои, победив Yoyodyne Bank и всех клиентов, уходящих из него,
встречаются с новыми трудностями. На этот раз ~~проклятые Бурнаши мост подожгли...~~  вероломные шпионы, летающие бортами
международных транспортных компаний собрались ~~украсть корону Российской Империи~~... ну, не знаю что. Шпионы в целом не
могут делать ничего путного. Так что нашим отважным чикистам придётся исхитряться и искать методы обнаружения преступников.

Для этой задачи коммитет ЧК предоставил [датасет с хайпера](https://drive.google.com/drive/folders/19bCT5pKF-QnfW05FW0Eb2dUsMrrnbUSD)
и неуловимые принялись заниматься оперативным расследованием.

Превым шагом было предложено конвертировать это всё в народный формат CSV. Для этих целей Валера, выучившийся в Ленинградской
академии кибернетики написал [скрипты-преобразователи](./scripts/csv_conv/).

Но мало данные распарсить, их надо ещё преобразовать. Вот тут-то и начинается веселье `:)`
